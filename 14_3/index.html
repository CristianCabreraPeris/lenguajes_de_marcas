¿Qué es Git?

Git es un sistema de control de versiones: un programa que guarda el historial de cambios de tus archivos para que puedas volver a cualquier punto anterior si algo sale mal.

Además, facilita el trabajo en equipo. Varias personas pueden modificar el mismo proyecto a la vez y Git ayuda a combinar sus cambios sin pisarse unas a otras.

Instalación y configuración

Puedes descargar Git desde su web oficial, git-scm.com, para Windows, macOS o Linux. En muchas distribuciones de Linux basta con instalarlo desde el gestor de paquetes.

Después de instalarlo, conviene indicar quién eres con los comandos git config --global user.name y git config --global user.email. Esos datos aparecerán en cada cambio que guardes.

Tu primer repositorio

Dentro de la carpeta de tu proyecto, ejecuta git init para crear un repositorio. A partir de ese momento Git vigila los cambios de esa carpeta.

Para guardar una versión, primero se preparan los archivos con git add . y luego se confirma con git commit -m "Mensaje descriptivo". Cada commit es una instantánea del proyecto que podrás recuperar más adelante.

Trabajar con ramas

Una rama es una línea de desarrollo independiente. Sirve para probar una idea nueva o arreglar un error sin tocar la versión principal del proyecto.

Con git branch creas una rama y con git checkout nombre te cambias a ella. Cuando el trabajo está terminado, se une a la rama principal con git merge nombre
