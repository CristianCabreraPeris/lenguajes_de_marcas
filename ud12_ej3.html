Ficha técnica: Visual Studio Code

Visual Studio Code es un editor de código utilizado para programar en diferentes lenguajes.

IDE es un término utilizado para referirse a un entorno de desarrollo que proporciona diferentes herramientas para programar.

En Visual Studio Code podemos escribir código como:

System.out.println("Hola mundo");

Para guardar un archivo podemos utilizar la combinación de teclas Ctrl + S.

Editor de código es un programa que permite escribir y modificar código fuente.

Visual Studio Code fue publicado por Microsoft en 2015.
